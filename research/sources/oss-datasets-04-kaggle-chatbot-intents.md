## About Dataset

**🇬🇧 English:**

This dataset contains 1000 synthetic chatbot user inputs, each labeled with its corresponding intent. It's ideal for training and evaluating intent classification models using NLP techniques.

**Use this dataset to:**

- Train classifiers to detect user intent
- Build end-to-end chatbot systems
- Experiment with BERT, Logistic Regression, Naive Bayes, etc.

* * *

**🇹🇷 Türkçe:**

Bu veri seti, kullanıcıların chatbot'a yazdığı 1000 sahte mesajı ve her mesajın niyet (intent) etiketini içerir. NLP tabanlı niyet sınıflandırma modelleri geliştirmek için uygundur.

**Bu veri seti ile:**

- Kullanıcı niyetini tahmin eden modeller geliştirilebilir
- Chatbot sistemlerinin doğal dil anlama yetenekleri artırılabilir
- BERT, Naive Bayes gibi NLP algoritmaları test edilebilir
