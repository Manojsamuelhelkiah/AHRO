# Dataset Card\
\
HR-Multiwoz is a fully-labeled dataset of 550 conversations spanning 10 HR domains to evaluate LLM Agent. It is the first labeled open-sourced conversation dataset in the HR domain for NLP research.\
Please refer to [HR-MultiWOZ: A Task Oriented Dialogue (TOD) Dataset for HR LLM Agent](https://arxiv.org/pdf/2402.01018.pdf) for details about the dataset construction.\
\
### Dataset Sources\
\
- **Repository:** [xwjzds/extractive\_qa\_question\_answering\_hr](https://huggingface.co/datasets/xwjzds/extractive_qa_question_answering_hr)\
- **Paper:** [HR-MultiWOZ: A Task Oriented Dialogue (TOD) Dataset for HR LLM Agent](https://arxiv.org/pdf/2402.01018.pdf)\
- **Leaderboard:** [github repo](https://github.com/amazon-science/hr-multiwoz-tod-llm-agent)\
\
### Direct Use\
\
This dataset has been designed to evaluate transfer learning ability for TOD system and SGD algorithm.\
\
### Out-of-Scope Use\
\
This dataset is not intended for use in training.\
\

### Data Fields\
\
The dataset comprises the following fields:\
\
-'dialogue\_id': an int that is the id of the dialogue\
-'service': a list contains relevant area of the dialogue\
-'turn\_id': a list of int which shows the turn id\
-'speaker': a list of int where 0 represents HR Assistant and 1 represents Employee\
-'utterance': a list of strings to represent the conversation\
-'state': the state of entity and answer in each turn after Employee speak\
