---
name: Security assurance documentation
description: Required audiences and coverage for the project's security and responsible-AI explainers.
---

The security explainer must cover security, privacy, responsible-AI metrics, the agent execution harness and the testing harness. Provide a business-user explanation and a separate shorter technical view for chief security officers and information-security heads.

**Why:** The user explicitly requested complete feature and metrics coverage, while noting that the business explanation alone is not the right format for technical security leadership.

**How to apply:** Reconcile both documents with current controls and evidence before describing coverage as comprehensive. Distinguish implemented controls, configuration-dependent assurance, measured results and roadmap work. Do not represent operational activity counts as proof of AI accuracy, fairness or regulatory compliance.
