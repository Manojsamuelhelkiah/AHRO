---
name: Administrator viewing agreement
description: Confidential client viewing is distinct from professional decisions and employee-owned consent
---

An authenticated, active Super Admin session may view confidential records in
its verified selected client without receiving a specialist assignment.
Eligibility, the shared account identity, and public Demo sign-in alone are
not active administrative privilege.

**Why:** The user explicitly restored the previously agreed administrative
viewing capability; requiring professional assignment for that viewing caused
incorrectly redacted operational case screens.

**How to apply:** Preserve session-bound, tenant-verified administrative reads
when evolving access policy. Never use this agreement to justify sensitive
editing, professional sign-off, independent review, source verification,
external execution, or access to personally owned Vault records without
consent. Check real provider MFA separately from isolated fixture tests.
