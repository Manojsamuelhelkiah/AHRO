---
name: Shared mailbox personas
description: Intended stakeholder names must remain distinct from actual delivery and authenticated responder identities.
---

The approval demonstration uses one mailbox for multiple named stakeholders. Treat intended persona, delivery address, and actual responder as separate identities.

**Why:** The user needs observers to understand who a communication represents even when all approvals arrive in the same inbox. A shared sender address cannot prove which named human replied.

**How to apply:** Show employee/case, initiating person or agent, intended stakeholder name and role, actual delivery address, and actual responder. Label demo acting-as identities as presentation metadata, never permission grants. Snapshot identities with outgoing messages so later name edits do not rewrite history. Do not silently reroute employee communications to the approval mailbox.
