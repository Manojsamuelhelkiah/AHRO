---
name: Client operating default boundaries
description: Administrative defaults and responsibility routing must remain separate from approved case policy and access authority.
---

Client business calendars are reusable proposals until explicitly adopted into an approved SLA policy. Saving operating defaults must not silently reschedule existing case obligations or replace case-specific logistics.

**Why:** Client setup convenience is not approval to change an established worker deadline or an already agreed arrival plan.

**How to apply:** Describe which new records inherit each default. Keep calendar adoption separate from administrative saving and use the existing policy revision and case-adoption safeguards when adding calendar execution later.

Routing queues and group references record responsibility, not professional authority, group membership, case access or a verified delivery address.

**Why:** Routing work to a named team must not accidentally grant permission to read employee data, approve a decision, or send sensitive information to an unverified mailbox.

**How to apply:** Preserve explicit assignment overrides, use only recorded case-family/country evidence, retain scoped group identifiers rather than inferring identity from a name, and separately recheck authorization and recipient binding before any notification or execution.
