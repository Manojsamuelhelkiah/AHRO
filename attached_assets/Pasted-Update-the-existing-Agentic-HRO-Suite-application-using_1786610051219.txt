Update the existing **Agentic HRO Suite** application using the attached/approved login-page visual concept as the **design reference and source of truth**.

The objective is to:

1. Implement the approved login-page visual direction.
2. Establish a reusable **Agentic HRO design system**.
3. Apply the same color, typography, spacing, surface, border, icon, and interaction language consistently across the ENTIRE application.
4. Ensure future screens can reuse the same theme without independently choosing colors.

Do NOT treat this as a one-page styling exercise.

This should become the application's **global visual language**.

---

# 26. IMPLEMENTATION STRATEGY

Before changing UI:

1. Inspect the existing application architecture.
2. Identify the current global CSS/theme system.
3. Identify reusable UI components.
4. Create or consolidate design tokens.
5. Update the shared components first.
6. Then propagate the visual system across screens.
7. Avoid one-off page-specific styles.
8. Remove duplicated color definitions where practical.
9. Do not rewrite business logic.
10. Do not change APIs or application behavior unless necessary for styling.

Prioritize maintainability.
