# 3. NEW CONTROL TOWER KPIs

Use:

### ACTIVE CASES

Display the number of currently active HR Operations cases.

---

### AUTONOMOUSLY RESOLVED

Display the percentage of eligible cases completed without human intervention.

Example conceptual presentation:

`94%`

Supporting context:

`Eligible cases completed autonomously`

IMPORTANT:

Only calculate/display this percentage if the existing application contains sufficient data to calculate it accurately.

Do not hard-code 94%.

If unavailable, show an appropriate unavailable state such as:

`—`

---

### HUMAN INTERVENTIONS

Display the number of cases currently requiring human judgment, approval, or exception handling.

Supporting context:

`Requires attention`

Use restrained amber semantics when the value is greater than zero.

---

### SLA AT RISK

Display active cases approaching or exceeding an SLA threshold.

Supporting context:

`Needs attention`

Use amber for at-risk cases.

Use red only for genuinely breached/critical states.

---

### BLOCKED CASES

Display cases that cannot continue because of a hard dependency, policy block, system failure, or unresolved prerequisite.

Supporting context:

`Unable to proceed`

Use red only when blocked cases actually exist.

If zero, use a healthy neutral/green state.
