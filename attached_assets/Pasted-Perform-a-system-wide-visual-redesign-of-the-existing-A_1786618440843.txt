Perform a **system-wide visual redesign of the existing Agentic HRO Suite**.

This is NOT a request to redesign one page.

The objective is to take the current application from a competent internal enterprise tool to a **premium, commercial-grade enterprise SaaS platform** with a distinctive **Agentic Operations** identity.

Use the approved Agentic HRO login-page direction as the visual starting point, but evolve the entire product beyond it.

The final product should feel:

**Premium enterprise SaaS + AI-native operations platform + governed automation + human-in-the-loop**

Benchmark the quality and restraint of products such as Linear, Stripe, ServiceNow, modern AI operations platforms, and leading enterprise SaaS products, but DO NOT copy their designs.

The goal is to establish an original **Agentic HRO design language**.

---

# 1. IMPORTANT: REDESIGN THE SYSTEM, NOT INDIVIDUAL SCREENS

Do NOT make small cosmetic changes to each page independently.

First establish a reusable **Agentic HRO Design System V2**.

Then migrate the existing application to that design system.

The most important outcome is:

> Every screen should look like it belongs to the same intentional product.

Avoid the current situation where each page looks like a slightly different enterprise admin screen.

Do not add more widgets merely to make pages look richer.

Improve:

* hierarchy
* typography
* information architecture
* whitespace
* surface depth
* interaction design
* consistency
* agent-centric visual language
* enterprise polish

---

# 2. FIRST: INSPECT THE EXISTING APPLICATION

Before changing UI:

1. Inspect the entire frontend structure.
2. Identify the current routing.
3. Identify the current component library/shared components.
4. Identify global CSS/theme files.
5. Identify duplicated color values.
6. Identify duplicated card/button/input styles.
7. Identify navigation components.
8. Identify dashboard components.
9. Identify cases components.
10. Identify agent/approval/guardrail/system components.
11. Identify any existing dark/light theme implementation.

Do NOT immediately rewrite pages.

First understand the current architecture.

Preserve business logic.

Preserve existing data flows.

Preserve authentication.

Preserve routes.

Preserve APIs.

Preserve database behavior.

# 6. TYPOGRAPHY REDESIGN

Typography should become significantly more sophisticated.

Create consistent levels.

### Display

Large hero/product statements.

### H1

Page titles.

Target approximately:
`30–36px`

### H2

Major section headings.

Approximately:
`20–24px`

### H3

Card/subsection titles.

Approximately:
`16–18px`

### UI body

Approximately:
`14–15px`

### Metadata

Approximately:
`12–13px`

### Micro labels

Approximately:
`11–12px`

Use carefully controlled font weights.

Do not bold everything.

Do not uppercase large amounts of body text.

Use letter spacing primarily for small operational labels.

Typography should establish hierarchy instead of relying heavily on borders or colors.

# 7. REMOVE THE "BOXED ADMIN PANEL" FEEL

This is one of the most important redesign requirements.

The current application relies too heavily on:

* borders
* cards
* bordered sections
* boxed navigation
* repeated rectangular containers

Reduce visible borders significantly.

Target roughly **30–40% fewer visible borders**.

Create hierarchy using:

* whitespace
* typography
* surface contrast
* subtle elevation
* alignment
* grouping

Use borders only where they improve comprehension.

Do not place every piece of information inside a card.
